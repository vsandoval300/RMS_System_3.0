Placement Schemes

A Placement Scheme defines how the premium on an Operative Document is distributed among the parties involved in a Business — cedants, intermediaries, and reinsurers — through a series of deductions and commissions. This manual covers how a scheme is structured, how its Cost Nodes work, and where it gets used elsewhere in RMS.

§

Before you start: a Placement Scheme is a standalone record, independent of any single Business. It's typically created once and then reused — selected, not recreated, whenever it applies to a new Operative Document. Deleting a scheme that's already attached to an Operative Document is blocked until it's detached.

Placement Schemes → Structure Details

1. Structure Details

Definition

Structure Details establish a Placement Scheme's identity — the reinsurance agreement type it represents, its share of the risk, and a description of its terms. Together with its Cost Nodes, this is the information other records reference when they select this scheme.

Every scheme begins here, whether created from the Placement Schemes list or inline from an Operative Document.

Placement Schemes → Cost Nodes

2. Cost Nodes

Definition

A Cost Node represents a single deduction, commission, or fee within a Placement Scheme, moving a percentage of the premium from one party to another. A scheme's Cost Nodes, taken together, define its full cost structure — the same structure previewed wherever the scheme is selected on an Operative Document.

Add one Cost Node per deduction or commission in the scheme. Rows can be reordered, and a running total is kept automatically.

Deduction TypeconceptRequired*Select the type of deduction or commission this Cost Node represents, from the Deductions catalog.

Placement Schemes → Using Placement Schemes

3. Using Placement Schemes

A Placement Scheme can be created on its own, ahead of time, or inline while setting up an Operative Document — both paths open the exact same form. Once created, it's selected wherever it applies.

A

Creating a Scheme

Both creation paths below use the identical Structure Details and Cost Nodes form described in sections 1 and 2 — only the entry point differs.

1

From the Placement Schemes list

From Underwritten → Placement Schemes, click + New Placement Scheme, top right. Fill in the Structure Details, add the scheme's Cost Nodes, and click Create — confirming in the dialog that appears.

2

Inline, from an Operative Document

From the Operative Document's Placement Schemes tab, click the + button next to the Placement Scheme selector. The same creation form opens in a modal, without leaving the Operative Document setup. On save, the new scheme is created and automatically selected.

B

In Operative Documents

Once created, a Placement Scheme is selected — not recreated — every time it applies to a new Operative Document.

1

Select an existing scheme

The Placement Scheme selector lists every scheme by ID, Index, Share, and Structure Agreement type, for example: SCHE-20260215-0003 · Index: 3 · Share: 70.00% · Type: Quota Share.

2

Review its Cost Nodes

Selecting a scheme reveals a read-only preview of its Cost Nodes — Concept, Source, Destination, and Value, with a running total — so the cost structure can be verified without leaving the Operative Document.

＋
The Placement Scheme(s) selected here determine which schemes are offered on the Insured Members tab. Removing a scheme from this list clears that selection on any Insured Member row that referenced it.
✓

A Placement Scheme, once created, is reusable across as many Operative Documents as apply to it — there's no need to recreate one just because it's used elsewhere. Build the scheme once, get its Structure Details and Cost Nodes right, and select it going forward.
